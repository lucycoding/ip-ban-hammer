# Security Policy / 安全策略

## Reporting a Vulnerability / 报告漏洞

**Please do not report security vulnerabilities through public GitHub Issues.**

**请不要通过公开的 GitHub Issue 报告安全漏洞。**

Instead, please report them using GitHub's private vulnerability reporting feature:

请使用 GitHub 的私有漏洞报告功能提交：

👉 [Report a vulnerability / 报告漏洞](https://github.com/lucycoding/ip-ban-hammer/security/advisories/new)

## What to Include / 报告内容

- Description of the vulnerability / 漏洞描述
- Steps to reproduce / 复现步骤
- Affected versions / 受影响版本
- Possible impact / 可能的影响
- Suggested fix (if any) / 修复建议（如有）

## Response Time / 响应时间

We aim to acknowledge vulnerability reports within 48 hours and provide a fix within 7 days.

我们会在 48 小时内确认漏洞报告，并在 7 天内提供修复。

## Supported Versions / 支持版本

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |
| < 1.0   | No        |
